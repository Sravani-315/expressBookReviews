WHAT THIS FILE CONTAINS:
------------------------

The general.js file contains the following async/await implementations with Axios:

1. getAllBooks() - Retrieves all books using async/await
2. getBookByISBN(isbn) - Retrieves book by ISBN using async/await
3. getBooksByAuthor(author) - Retrieves books by author using async/await
4. getBooksByTitle(title) - Retrieves books by title using async/await

All implementations use Promise callbacks with async/await and Axios for concurrent operations.
